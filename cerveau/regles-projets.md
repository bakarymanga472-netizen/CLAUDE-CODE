# Règles d'isolation des projets

1. Un projet = un dossier `projets/<nom>/`. Rien d'un projet ne s'écrit dans le dossier d'un autre.
2. Avant de travailler sur un projet, annonce lequel et lis son `contexte.md`.
3. Si une demande est ambiguë sur le projet concerné, demande avant d'agir.
4. Les infos réutilisables par plusieurs projets vont dans `cerveau/contexte/`, pas dans un projet.
5. Dans Notion, chaque tâche porte le nom de son projet.
