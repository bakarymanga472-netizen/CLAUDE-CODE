---
name: fin-de-session
description: Sauvegarde la mémoire en fin de session. Utiliser quand je dis "fin de session", "on s'arrête", "sauvegarde".
---
1. Écris `cerveau/memoire/sessions/AAAA-MM-JJ-<sujet>.md` : ce qui a été fait, décisions, fichiers modifiés (10 lignes max).
2. Réécris `cerveau/memoire/maintenant.md` : en cours, prochaines actions, blocages.
3. Mets à jour `projets/<projet>/contexte.md` pour chaque projet touché.
4. Liste les tâches à reporter dans Notion et propose de les y créer.
5. Propose un commit git (`scripts/sauvegarde.sh "<message>"`) — n'exécute qu'avec mon accord.
