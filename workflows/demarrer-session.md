# Démarrer une session

**Déclencheur :** chaque nouvelle session.

1. `cd` dans ce dossier, lance `claude`.
2. Dans Obsidian : « Git: Commit-and-sync », pour que Claude voie tes dernières notes.
3. Dis : « Lis maintenant.md, trie l'inbox, puis résume où on en est. »
4. Choisis le projet du jour → Claude lit son `contexte.md`.
5. En fin de session : demande de mettre à jour `cerveau/memoire/maintenant.md` et le `contexte.md` du projet.
